# Career Lifecycle Workspace

IT 이직 라이프사이클을 반복해서 운영하는 개인용 AI 작업환경이다. 공고를 발견한 뒤에 서류를 만들기 시작하는 방식이 아니라, 공고 전에 90%를 준비해 두고 기회가 오면 기업별 10%만 더해 제출한다.

## 운영 방식

| 단계 | 하는 일 | 산출 위치 |
|---|---|---|
| 1 | 경험 원재료 목록화 → 목표 직무 A/B/C와 기업 지도, 공고 감지 체계 | `package/experience-inventory.md`, `package/target-map.md` |
| 2 | 대표 경험을 문제–판단–행동–결과–학습 자산으로 심화 | `package/experience-assets/`, `inputs/profile/` |
| 3 | 90% Ready-made 패키지와 READY 판정 | `package/` |
| 4 | 공고 저장과 Go/No-Go 판정 | `pipeline/postings/`, `pipeline/triage/` |
| 5 | 기업별 10% 맞춤화와 제출 | `outputs/{회사-직무}/` |
| 6 | 사전과제·면접·레퍼런스 실행 | `outputs/{회사-직무}/` |
| 7 | 회고와 마스터 패키지 개선 | `pipeline/retrospectives/`, `package/` |

1~3단계는 한 번 만들어 두고 계속 고치는 시스템이고, 4~7단계는 공고마다 반복한다.

## 시작하기

Claude Code, Codex, Antigravity처럼 로컬 폴더를 읽고 쓸 수 있는 AI 에이전트에서 이 폴더를 연다. 별도 설치나 터미널 명령은 필요하지 않다.

처음 시작할 때:

> 이 폴더의 AGENTS.md를 먼저 읽고 따라줘. 1단계부터 시작해서 내 경험을 전부 정리한 다음 목표 직무 A/B/C를 같이 정하자.

이미 1~3단계가 준비된 뒤 새 공고를 발견했을 때:

> 이 공고 저장하고 Go/No-Go부터 판정해줘.

패키지를 고치고 싶을 때:

> 마스터 이력서의 대표 경험 순서를 다시 보고 싶어. READY 판정도 다시 해줘.

## 자료 넣는 곳

- `inputs/private/sources/` — 경력 원본 데이터
- `inputs/주로제출하던이력서와포트폴리오/` — 실제 제출해 온 이력서·자기소개서·포트폴리오
- 대화에 직접 첨부해도 된다. 원본 파일은 에이전트가 수정하지 않는다.

읽을 수 없는 형식이면 에이전트가 설치를 요구하지 않고 대체 형식을 요청한다.

## 기본 동작

- 입력: PDF, DOCX, Markdown, HTML, JSON, TXT
- 기본 출력: Markdown. 선택 출력: 런타임이 지원할 때 DOCX 또는 HTML
- PDF는 입력 전용이다. 포트폴리오는 페이지 편집 지시서까지 만들고 디자인 실작업은 사용자가 한다.
- 원본과 개인 자료는 읽기 전용이며, 기준 프로필 갱신은 사용자 승인 후에만 반영한다.
- 없는 경력·수치를 만들지 않는다. 근거가 불확실하면 범위와 추정 여부를 표시한다.

## 개인정보

`inputs/private/`, `inputs/profile/`의 실제 파일, `inputs/주로제출하던이력서와포트폴리오/`, `package/`, `pipeline/`, `outputs/`는 공유하거나 버전 관리하지 않는다.

## 이용 범위

개인 연구, 학습, 실험과 자신의 채용 지원 준비에 사용한다. 프로젝트나 그 결과를 이용한 유료 이력서 작성, 취업 컨설팅, 코칭, 채용 대행, 교육 제공과 상업적 재배포는 하지 않는다.
