# Inputs

이 환경은 한 명의 지원자 프로필과 제출 원본을 지속적으로 재사용한다.

- `private/sources/` — 사용자가 제공한 경력 원본 데이터. 에이전트는 수정하지 않는다.
- `profile/` — 승인된 기준 프로필, 근거 장부, 자산과 변경 이력.
- `주로제출하던이력서와포트폴리오/` — 실제 제출해 온 문서. 3단계 마스터의 형식 권위이며 읽기 전용이다.
- `IT 대기업 상향 이직 웨비나/` — 라이프사이클 7단계와 20개 작업의 근거 문서.

프로필은 경력 사실을 재사용하기 위한 자료이고 문서의 페이지, 섹션, 문단, 표와 이미지 구조를 대신하지 않는다. 마스터와 회사별 제출본은 항상 실제 제출 원본의 구조를 권위로 삼는다.

파일에서 확인할 수 없는 사실(최근 재직, 수치의 계산 근거, 실패·갈등 사례)은 2단계 인터뷰로 확보하고 근거 장부에 `self-reported`로 등재한다.

실제 프로필 파일, 개인 원본과 제출 원본은 `.gitignore`로 공유 대상에서 제외된다.
